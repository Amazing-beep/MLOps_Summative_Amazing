How it works

  1. Predict. Enter an encounter (or load a real example) and get the probability of readmission within 30 days, with the factors driving it.
  2. Upload. Add a labelled CSV. It is validated, then stored in a SQLite database.
  3. Retrain. The pre-trained LightGBM model is fine-tuned on the stored data using the same preprocessing; the new version is evaluated before/after and can be activated or rolled back.
